# Студия одежды

Проект открывает персонажа из одного GLB с готовым ригом и встроенными движениями. В примерочную можно импортировать отдельные GLB одежды, создать детали из шаблонов или соединить замкнутые контуры из SVG. В режиме подгонки работайте с отдельной вещью или её частью. Кисть меняет форму сетки, а кнопка «Рассчитать веса и примерить» привязывает одежду к костям персонажа. Если веса уже рассчитаны, правка формы запустит их пересчёт перед новым просмотром.

Для пластины выберите жёсткую привязку и укажите кость. Для тканевой вещи оцените посадку на нескольких кадрах. Эта версия рассчитывает деформацию по весам костей. Швы SVG соединяют выбранные пары краёв в сетку, физика ткани и автоматическая проверка пересечений пока отсутствуют.

В «Ткань и рисунки» загрузите PNG, JPG или WebP. «Текстура ткани» покрывает выбранную вещь или её деталь. «Нанести рисунок» позволяет поставить изображение пальцем и настроить размер, поворот и непрозрачность. Расположенный рисунок использует веса сетки одежды и входит в экспорт GLB вместе с изображением.

«Каталог одежды» создаёт футболку с выбранным дизайном, толстовку с капюшоном или джоггеры. «Ткань и рисунки → Участок» позволяет отдельно оформлять перед, спинку и рукава футболок и толстовок. Готовый принт можно заменить своим изображением, сохранив его положение.

«Мои материалы» хранит текстуры, декали, модели 3D-декора и выкройки SVG на устройстве. Выберите «Кроить» у текстуры и нарисуйте контур или откройте выкройку. UV-координаты полотна сохраняют положение рисунка на ткани. Толщина добавляет изнанку и кромки. Операция «Добавить слой» копирует выбранную сетку и смещает её внутрь или наружу. Непрозрачность, вырез по альфе и матовость задаются для выбранного материала.

«Ткань в движении» закрепляет верх выбранного полотна и рассчитывает движение свободного края с приближёнными коллизиями ног. В окне экспорта включите запекание и укажите клип, затем выберите «Персонажа в одежде». Новые ключи деформации добавятся в выбранный клип. Исходные скелетные дорожки и остальные клипы GLB сохраняются. Для многослойных вещей оценивайте пересечения в примерочной, симуляция не рассчитывает контакты между слоями ткани.

## Сборка

```sh
npm ci
npm run typecheck
npm test -- tests/wardrobe.test.ts tests/wardrobe-print.test.ts tests/wardrobe-catalogue.test.ts tests/wardrobe-materials.test.ts
npm run build:wardrobe
```

Офлайн-страница находится в `wardrobe-dist/wardrobe/index.html`. Для Android используйте `python3 scripts/assemble-wardrobe.py STUDIO-8.2.10-BASE.apk wardrobe-unsigned.apk`, затем выровняйте APK через Android SDK и подпишите своим ключом. Сборщик ожидает контейнер Studio 8.2.10 с файловым экспортом Android. Приложение устанавливается под пакетом `com.rayzen.riganimationstudio.wardrobestudio`.
