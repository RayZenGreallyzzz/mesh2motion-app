# Rig Animation Studio v8.1.6 test APK

This build packages the creature-fit follow-up with the complete private
animation library. It keeps application ID
`com.rayzen.riganimationstudio.v815test`, increments versionCode to 816 and
versionName to 8.1.6, and uses the privately retained v8.1.5 test key. It updates
the installed v8.1.5 package; uninstalling the older package would erase that
package's local imported models and settings.

The native shell comes from the verified v8.1.4 APK. Its compiled native code
is reused; scripts/repack-private-library.py replaces the validated web build
and patches the package/version metadata. The result must be aligned, signed
and verified locally. Private animations, full APKs and signing material are
not public repository outputs.

Validation for this build covers 48 editor/weight/fitting regressions, 150
library and native-animal regressions, TypeScript checking and the full-library
web build. All 63 private GLBs remain byte-identical to the supplied backup,
all 122 original Mesh2Motion GLBs match the verified native base, and 49
embedded images decode. The complete catalog contains 742 clip entries,
including Standard/RootMotion variants of the same 43 UAL2 actions.

The fitting changes improve independent quadruped paws, low arms on large-headed
bipeds and incorrect finger influence on broad ears. This release does not
establish universal autorigging, fix all bird/dragon anatomy, add trunk/tail
chains to a human rig, or include RigAnything inference. Physical Android
installation, UI interaction and deformation review remain device checks.
