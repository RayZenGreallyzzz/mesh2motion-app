# Rig Studio v6.7 TEST

База: v6.6, `510ede4d7830a7481fc30e530fb48df6353e75a1`.
Ветка: `codex/rig-studio-v67-animal-fit`. PR: https://github.com/RayZenGreallyzzz/mesh2motion-app/pull/8

## Изменения

- AutoRig в общей локальной системе координат; Undo до первой мутации.
- Общий граф поверхности для всех частей персонажа. Исходные веса кэшируются отдельно от ручной кисти; первый расчёт исполняется в Web Worker.
- Редактируемая подгонка восьми шаблонов животных. Для четвероногих с передними и задними цепочками лап используются опоры и внутренние сечения корпуса. Поднятый тонкий хвост отделяется от корпуса; кости хвоста могут следовать изгибу.
- Ретаргетинг животных и импорт GLB учитывают исходные оси костей. Исправлены регистр при зеркалировании, центральные дорожки хвоста/корня, касательные CUBICSPLINE и повторное добавление импортируемых `.bones[...]` дорожек.
- Поддерживающие кости известных сгибов животных сохраняются при экспорте GLB. После отказа экспортера модель возвращается в рабочую сцену.
- Скрыт неиспользуемый arm plane; ползунок разведения рук подписан как угол. Сохранены отступ панели и повторный touch-drag из v6.6.
- Отдельный Android package `.v67test`.

## Проверки

174 модульных/интеграционных теста: стык двух мешей при сгибе 140° (зазор <1e-6), инвариантность подгонки относительно общего трансформа, исходный Undo, восемь реальных комплектных моделей, определение корпуса с высоким шипом и пустотой между лапами, эквивалентность worker и синхронного расчёта, изоляция кэша, импорт без дублирования, восстановление сцены после ошибки экспорта.

GitHub Actions дополнительно выполняет Chromium Worker с проверкой отзывчивости и повторного кэшированного вызова, полный процесс Fox от загрузки до анимации и повторного импорта GLB с поддерживающими костями, 292 сэмплированных кадра восьми библиотек животных и повторные движения ползунка с 7% на четырёх размерах экрана.

На пользовательских моделях Warboar (234032 вершины), Magma Lizard (52017) и Graffiti Alley Cat (108595) проверены 824 сэмплированных кадра без NaN и ошибок исходной привязки, максимальное отклонение bind <5e-8. Бег/ходьба просмотрены на проекциях реально деформированной сетки. Эти числа не доказывают анатомическую точность каждого кадра. Первый расчёт кабана занимает около 7–8 секунд на сервере; это не замер Android.

## Ограничения

Автоподгонка даёт начальную редактируемую расстановку. Шаблон должен соответствовать строению существа. Необычные лапы, короткий/асимметричный хвост, броня, украшения и отверстия в сетке требуют ручной проверки суставов/весов. Полностью автоматическая сегментация одежды и жёстких деталей не реализована. Коррекции объёма охватывают известные сгибы; это не полноценный DQS-деформатор или система контакта лап с землёй.

На физическом Android-устройстве версия ещё не проверена. Полный `tsc --noEmit` сохраняет ошибки базового проекта; успешная сборка Vite не заменяет проверку типов.

## Воспроизведение

```sh
npm ci
npm test -- --run
npm run build
npm install --no-save playwright
npx playwright install --with-deps chromium
node scripts/check-rig-studio-worker.mjs
node scripts/check-rig-studio-flow.mjs
node scripts/check-rig-studio-touch-panel.mjs
node_modules/.bin/esbuild scripts/check-rig-studio-animals.ts --bundle --platform=node --format=esm --packages=external --outfile=scripts/check-rig-studio-animals.mjs
node scripts/check-rig-studio-animals.mjs
```

Скрипт животных принимает необязательный JSON-массив `{name,file,type}`. Пользовательские модели не включены в репозиторий. Результаты сохраняются в `artifacts/rig-check` либо в `RIG_CHECK_OUTPUT`.
