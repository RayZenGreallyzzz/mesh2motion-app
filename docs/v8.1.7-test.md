# Rig Animation Studio v8.1.7 test

This release adds the optional, reversible motion-aware weight check described
in `motion-weight-repair.md`. Its Android package is
`com.rayzen.riganimationstudio.v817test`, versionCode 817, versionName 8.1.7.
It installs alongside v8.1.6. It does not overwrite that installation or
automatically migrate its locally imported models/settings.

The supplied v8.1.6 APK was verified by SHA-256 and its v2/v3 signature before
reusing its native shell and recovering the complete library. All 185 GLB assets,
including 63 private converted packs with 742 clip entries, are retained byte
for byte. No purchased assets or signing material are public repository files.
The original private signing key was unavailable; a separate key is retained in
the private build backup for future updates of the v817test package.

## Validation

The 59 editor/weight regression checks (including 11 new tests) and all 150
library/native-animal checks pass, as do TypeScript and the complete-library
web build. The APK is aligned, signed with v2/v3 signatures and checked against
the built web assets. Native DEX files are unchanged from the supplied shell.

Two newly attached, initially unrigged meshes were also processed with the
production humanoid fitter, hand pruning, surface weight solver and joint-volume
support. The muscular human has 203,062 vertices. The large-headed upright
Vulpix character has 1,107,139 vertices and exceeds the motion check's memory
budget. A separate copy was reduced with meshoptimizer to 79,614 vertices and
119,976 triangles; original embedded texture bytes remain unchanged. This
offline simplification is not an automatic new editor feature.

Two calibrated native motions per character were checked at five times each,
for 20 sampled poses total. Measured over-stretched welded edge occurrences
decreased from 53,805 to 44,734 on the human and from 47,277 to 38,829 on Vulpix.
Independent evaluation found no newly flipped or severely collapsed triangles
in those samples. Both actual exported GLBs were reopened: each retains 62
bones, two clips, support-bone tracks, normalized finite weights and the original
embedded image bytes. Bind-pose errors remain below 1e-5 scene units.

## Known limitations

Visual inspection still shows the human pectoral region following the arms and
stretched clothing on Vulpix. Peak edge stretch is not eliminated (approximately
8.5x and 29.2x respectively in these samples). A lower aggregate stretch count
does not establish anatomical correctness. This is not a complete elbow/knee or
automatic garment solution. No independent tail articulation is added to the
human skeleton. Unselected clips and intermediate frames require review.

The test models are opened through **Мои риги → Открыть GLB** to keep their
saved skeleton, weights and clips. The separate animation-free Vulpix-Android
copy is intended for a fresh editor autorig. Original uploaded models remain
unchanged. There has been no installation or interactive test on a physical
Android device.
